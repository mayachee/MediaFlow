# Soudeni production project

This folder groups the song-specific scripts previously at the workspace root.
They contain specialized score/lyrics data and can write MIDI, WAV, PDF, and
MusicXML outputs alongside the scripts.

Suggested order:

1. `soudeni_piano_cover.py` creates the cover MIDI and prints the arrangement.
2. `generate_audio.py` creates a procedural piano render, or
   `create_full_production.py` creates and renders the orchestration.
3. `generate_vocals.py` optionally creates experimental TTS vocals and a mix.
4. `generate_pdf.py` and `generate_sheet_music.py` create score documents.
5. Pass a reviewed WAV to the root `workflow.py --audio` command to create a video.

From the workspace root, consistently export or compare a finished production:

```powershell
py -3.11 workflow.py --audio projects/soudeni/soudeni_aya_moghraman_cover_full_production.wav --preset master --wav-format float
py -3.11 workflow.py --audio projects/soudeni/soudeni_aya_moghraman_cover_full_production.wav --preset preview --preview-seconds 25
```

Add `--reference path/to/reference.wav` for a measured comparison and matched
listening clips. Normalization is off unless explicitly selected with
`--normalize peak` or `--normalize loudness`; limiting additionally requires
`--allow-limiting`. See [the production guide](../../docs/PRODUCTION.md).

Shared synth resources are in `vendor/fluidsynth-bin/` and
`assets/soundfonts/SoundFont.sf2` at the workspace root. Optional Python
dependencies are listed in `requirements/production.txt`.

The MIDI inspection scripts expect an orchestrated MIDI generated by this project.
Some scripts perform work immediately when run or imported; execute them
individually, and use `tests/` for automated test discovery.
